# Data Directory

This directory contains static data files used by the AI Resume Screening System.

## Files

| File | Purpose |
|------|---------|
| `market_standards.json` | Job category requirements and skill benchmarks |
| `learning_resources.json` | Curated learning resources for skill gaps |

## market_standards.json

Contains job category definitions with:
- Required skills and minimum proficiency levels
- Recommended skills for career growth
- Nice-to-have skills
- Market demand percentages

## learning_resources.json

Contains curated links to:
- Free online courses (FreeCodeCamp, Coursera, etc.)
- Tutorials and documentation
- Project ideas for skill building
