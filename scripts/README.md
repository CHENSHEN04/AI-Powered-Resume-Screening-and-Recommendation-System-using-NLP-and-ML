# Scripts Directory

This directory contains utility scripts for the AI Resume Screening System.

## Available Scripts

| Script | Purpose |
|--------|---------|
| `train_models.py` | Train TF-IDF vectorizer and SVM classifier from HuggingFace dataset |

## Usage

```bash
# Train models (run before first deployment)
python scripts/train_models.py

# Output files will be saved to models/ directory
```
